Privacy Policy

Nazarick Albedo · effective 13 October 2026

1. Who uses this app

Nazarick Albedo is a private assistant used by exactly one person, its owner, with the owner's own Google accounts. It is not a public service and no other person can use it.

2. Google data accessed

  • gmail.readonly – reading e-mail messages (no sending, no deleting).
  • calendar – reading events; creating, changing or deleting events only after explicit confirmation by the owner.
  • drive.readonly – reading files (no uploading, changing, sharing or deleting).
  • Basic profile and e-mail address – to identify which of the owner's accounts is connected.

3. How the data is used

Google data is used only to answer the owner's own requests (for example summarising e-mails or listing calendar events). It is processed by software running on computers owned by the owner. It is not used for advertising, not sold, not used to train AI models and not transferred to any third party.

4. Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Storage and security

OAuth tokens are stored only on the owner's computers, in a directory accessible only to the owner's operating-system account. No Google data or tokens are stored on any external server.

6. Retention and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the locally stored tokens ends access immediately.

7. Changes

Changes to this policy are published on this page with a new effective date.
